# dormitory-booking
#  Жатақхана бөлмелерін брондау жүйесі

PHP және MySQL негізінде жасалатын веб-қосымша. Студенттер бос бөлмелерді қарап, жатақханадан орын брондай алады, ал әкімші (admin) өтінімдерді қарап, бекітеді немесе қабылдамайды.

> Курстық жеке жобалық тапсырма (PHP, 8 апта).

## Жобаның мақсаты

Жатақханадан орын алу процесін қағазбастылықсыз, онлайн форматқа көшіру: бөлмелердің бос/бос емес күйін көрсету, брондау өтінімін қабылдау және әкімшіге басқаруды жеңілдету.

##  Мүмкіндіктер

**Студент (user):**
- Тіркелу, кіру және шығу
- Бөлмелер тізімін қарау (ғимарат, қабат, сыйымдылық, баға)
- Бөлмелерді іздеу және сүзу (ғимарат, қабат, баға бойынша)
- Бөлмені брондау (өтінім жіберу)
- Өз брондауларын қарау, өзгерту және бас тарту
- Профиль беті

**Әкімші (admin):**
- Ғимараттар мен бөлмелерді қосу, өзгерту, жою (CRUD)
- Брондау өтінімдерін қарау, бекіту немесе қабылдамау
- Пайдаланушылар тізімін көру
